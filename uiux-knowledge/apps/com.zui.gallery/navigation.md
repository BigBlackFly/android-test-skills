# 图库导航与状态关系

[返回App](README.md) · [功能索引](functions.md)

用于规划应读取的页面。表中区分明确的设计跳转与未明确的后续结果；不可把“可见按钮”自动推成完整流程。

## 主导航

| 起点 | 入口/动作 | 目标知识 | 边界 |
|---|---|---|---|
| 图库首页 | 所有照片 | [所有照片](pages/all_photos/README.md) | 日期地点分组媒体列表 |
| 图库首页 | 所有相册 | [所有相册](pages/all_albums/README.md) | 相册卡片，不是媒体多选页 |
| 左侧系统相册或系统相册卡片 | 选择分类 | [系统相册](pages/system_albums/README.md) | 部分入口为空时隐藏 |
| 左侧我的相册或用户相册卡片 | 选择相册 | [我的相册](pages/my_albums/README.md) | 名称/内容/多选管理 |
| 首页齿轮 | 点击 | [设置面板](pages/settings/README.md) | 模态面板形式 |
| 更多相册 | 隐私相册 | [隐私相册](pages/private_album/README.md) | 先验证身份；入口可隐藏 |
| 更多相册 | 最近删除 | [最近删除](pages/recently_deleted/README.md) | 自有恢复/永久删除操作 |
| 所有相册智能分类卡片等 | 点击 | [智能分类](pages/smart_albums/README.md) | LLSI Pro/18.0设计范围 |
| 左侧搜索 | 点击 | [AI搜索](pages/ai_search/README.md) | 同上；版本能力需确认 |

## 浏览及管理

| 当前情境 | 操作 | 后续状态/资料 |
|---|---|---|
| 普通媒体列表 | 点照片 | [照片详情](pages/photo_detail/README.md) |
| 普通媒体列表 | 点视频 | [视频详情](pages/video_detail/README.md)，初始暂停 |
| 照片详情 | 左右滑动/双指/下滑 | 换照片/缩放/退出详情 |
| 照片详情检测到文字 | 点OCR | [OCR状态](pages/ocr/README.md) |
| OCR | 左右切图，或指定顶部功能 | 按OCR文档退出识别；收藏例外 |
| 所有相册子相册 | 顶部返回 | 所有相册 |
| 媒体多选 | 添加到→选目标相册 | [移动/复制弹窗](pages/all_photos/README.md) |
| 已有待添加媒体，目标相册选择页 | +→新建→确认 | 添加方式选择，不再按先建空相册流程理解 |
| 左侧新建或所有相册+ | 名称→确定 | [选择照片](pages/my_albums/README.md)；未选完成可生成空相册 |
| 用户相册 | 重命名→确定 | 成功回初始界面；同名留在弹窗 |
| 普通相册 | 删除确认 | [最近删除](pages/recently_deleted/README.md)；涉及云端时确认文案不同 |
| 最近删除 | 删除确认 | 永久删除，无法恢复 |
| 最近删除 | 恢复 | 恢复入口明确，落点和反馈未明确 |

“返回初始界面”沿用原稿，未明确层级时不推成首页或自动退出多选。

## 隐私与同步

| 当前情境 | 操作 | 后续状态/资料 |
|---|---|---|
| 普通照片多选/详情 | 加入/移入隐私 | [隐私移入](pages/private_album/README.md)，大文件和数量分支 |
| 隐私相册多选/详情 | 移出 | 移出进度/系统loading，目标相册未说明 |
| 隐私相册 | 分享 | 确认→解密进度→系统分享；失败中断 |
| 隐私相册 | 删除确认 | 永久删除，仍停留隐私相册 |
| 隐私相册退后台后返回 | 回前台 | 重新身份验证 |
| 设置 | 隐藏隐私相册开启 | 相册入口隐藏，不等同删除内容 |
| 设置/照片浮窗 | 开启自动同步 | [账号及同步](features/cloud_sync/README.md) |
| 同步进行中 | 下载完成 | 转上传；同步完成提示消失 |
| 云空间提示 | 去购买 | 购买弹窗仅示意，完整付费过程未知 |

## 桌面及外部调用

| 起点 | 操作 | 后续状态/资料 |
|---|---|---|
| 未配置widget | 点击 | [照片管理空态](pages/widgets/README.md)→添加→选择照片 |
| 已配置widget | 点图 | widget照片预览；仅遍历管理集合 |
| widget长按 | 编辑/X | 照片管理/移除widget |
| 其他App | 选择照片 | [外部选择器](pages/external_picker/README.md) |
| 外部选择器 | 点缩略图 | 返回调用方的照片界面/状态，不进普通详情 |
| 媒体多选 | 长按并拖动 | [跨应用跟手状态](features/drag_drop/README.md)，接收结果未说明 |
| 系统App调用已卸载图库 | 首次调用 | [恢复安装提示](features/lifecycle/README.md) |
| 系统App调用停用图库 | 启用 | 系统设置应用页，手动启用 |

## 当前仍缺少完整规则的目标

系统分享目标页、Lenovo ID登录页、AI Lens完整工具、Writing Tools、文档扫描编辑器、云空间购买页、系统打开方式、密码验证错误/锁定流程。它们可能实际存在，但本包不臆造其内部页面。
