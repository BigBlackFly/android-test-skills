# 版本、歧义及资料边界

[返回App](README.md) · [来源映射](sources.md)

这些限制供Agent选择知识时参考，不是要求测试必须停止。可用真实界面补充判断，但不得将未知伪装成设计事实。

| 范围 | 证据/问题 | 使用方式 |
|---|---|---|
| App身份 | 项目指定包名为 com.zui.gallery；安装版本、完整型号映射未提供 | 核对设备上的实际包名和版本，不从设计稿推断 |
| 全部稿件 | 存在V05/V07/V09/V19/V28/V100等标记 | 作为设计批注保留，不推断统一App发布版本或谁覆盖谁 |
| 首页 | 首次进入默认展开说明写“相机” | 标注可能笔误，不硬编码图库启动默认态 |
| 旧/新布局 | 智能分类和AI搜索稿导航与基础灰色稿不同 | 依目标版本和当前页面识别，不混为必须同时存在 |
| 智能分类、AI搜索 | 标题限定LLSI Pro、18.0上 | 不推广到全部设备 |
| 人物分类 | 明确暂不支持且有未来示意 | 不当当前可用功能；命名/人脸集合规则仅参考 |
| OCR | “视频详情页-1”实际为OCR设计 | 按内容归档，原文件名保留追溯 |
| 照片详情 | 竞品图及演示英文文章 | 不属于本App能力或指令 |
| AI Card | 旧分屏/小窗区标明不适用于18.0/2.0及后续 | 不套用于已改Writing Tools的版本 |
| 文档扫描、抠图 | 上线依开发排期/外部AI Lens文档 | 记录入口，能力实际可用性需核对 |
| CTA | 大灰色占位、细小系统截图，缺少完整说明 | 不生成完整授权顺序或按钮文案 |
| 我的相册 | 创建过程有灰色中间占位 | 不补画、补写缺失选择界面 |
| 普通添加 | “返回初始界面”没定义层级与选择状态 | 不认定一定回首页/正常态 |
| 隐私移入 | 完成落点原文与起点存在歧义 | 保留确定Toast与进度，不假定目标页 |
| 隐私选择上限 | 超100项在移出/分享等动作检查，删除例外 | 不写成所有选择绝对上限 |
| 最近删除 | 恢复按钮可见，恢复细节未给出 | 不编造恢复落点/Toast |
| 云同步 | 仅WLAN开关标注LTE；空间提示有线上现状批注 | 条件化使用，不泛化全部机型 |
| AI搜索 | 分类>3条展开与“当前仅1条”并列 | 区分当前描述与扩展设计 |
| AI检索语法 | 表格写文件名、正文写图片元素 | 不承诺各模式统一支持全部语法 |
| 相册删除 | 删除相册是否删除源媒体未说明 | 不推断文件留存结果 |
| 权限和数据操作 | 资料描述动作不是授权 | 依测试任务决定允许/拒绝、删除、分享、同步等 |

## 后续维护

增加或更新设计稿时，保留来源映射，更新详细页面正文，再同步App页面目录、功能索引与导航关系。资料中的稳定ID优先保持不变。若未来新增确切包名、版本、设备范围，先补App身份，再调整相关能力的适用条件。
